🔄 Areas Loading Test - Reload Scenario

Objetivo: Verificar que las áreas se cargan correctamente después de recargar la página

🎯 Escenario de Prueba Crítico

Este test verifica el problema reportado: "recargar la página e hice la prueba nuevamente y otra vez no me cargó la selección de áreas según el grado que elegí"

📋 Procedimiento de Prueba

  1. Prueba inicial: Completar el formulario normal (Step 1 → Step 2)
  2. Recargar página: Presionar F5 o Ctrl+R
  3. Repetir prueba: Volver a llenar Step 1 → ir a Step 2
  4. Verificar: ¿Se cargan las áreas en el segundo intento?

🔧 Diagnóstico de Problemas

Problema 1: Estado se pierde al recargar

Síntoma: Al recargar, formData.id_grado y formData.id_convocatoria son undefined

Solución: El estado debe persistir o reinicializarse correctamente

Problema 2: Timing de inicialización

Síntoma: useAreasSelection se ejecuta antes de que formData tenga valores

Solución: Esperar a que formData esté completamente inicializado

Problema 3: Step inconsistente

Síntoma: isStep2 es true pero no hay datos de grado

Solución: Validar que tengamos todos los datos necesarios antes de hacer API call
