Debug: Areas Loading Issue

Paso 1: Abrir la aplicación

1. Navegar a http://localhost:5175/registration

2. Abrir las herramientas de desarrollador (F12)

3. Ir a la pestaña "Console"

Paso 2: Llenar el formulario

1. Llenar los campos básicos (Nombres, Apellidos, CI, etc.)

2. Prestar atención al campo "Grado" - cuando selecciones un grado, deberías ver en la consola:

  • ✅ "Grado seleccionado: [numero]"
  • ✅ "🎯 useStudentForm: handleFormChange para id_grado"
  • ✅ "📊 useStudentForm: formData cambió"

Paso 3: Hacer clic en "Siguiente"

Al hacer clic en el botón "Siguiente", deberías ver estos logs en orden:

  1. ✅ "📋 RegistrationPage: Paso 1->2 - Datos del formulario"
  2. ✅ "🔍 RegistrationPage: formData values antes de useAreasSelection"
  3. ✅ "🚀 useAreasSelection: Hook inicializado con formData"
  4. ✅ "🔄 useAreasSelection: useEffect disparado"
  5. ✅ "🔍 fetchAreasPorGrado ejecutado"
  6. ✅ "✅ Condiciones cumplidas, haciendo llamada API"
  7. ✅ "🌐 API: getAreasPorGrado llamada con: {idGrado: X, idConvocatoria: Y}"

Puntos de falla comunes:

  • ❌ Si no ves "Grado seleccionado" → El evento onChange no se está disparando
  • ❌ Si ves "❌ Condiciones no cumplidas" → id_grado o id_convocatoria están vacíos
  • ❌ Si no ves logs de la API → La llamada no se está realizando
  • ⚠️ Si los valores aparecen como undefined o null → Problema de estado

Datos esperados en los logs:

id_grado: Debe ser un número (ej: "5", "6", "12")

id_convocatoria: Debe ser "1" (según los logs anteriores)

Tipo: Ambos deben ser "string" inicialmente, pero convertidos a number en la API
